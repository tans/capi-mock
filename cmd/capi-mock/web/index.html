capi-mock
在线模拟服务 GitHub

让 Agent 先把接口跑通。

capi-mock 提供固定、可重复的模型响应。用它验证 CAPI 的渠道配置、请求格式、流式输出和异步任务轮询，无需真实模型账号或产生模型调用费用。

开始测试 查看接口清单

快速开始

全部模型接口使用 Bearer Token。先复制这段请求验证连通性。

curl https://capi-mock.minapp.xin/v1/models \
  -H 'Authorization: Bearer mock-key'
配置 CAPI 渠道：Base URL 填 https://capi-mock.minapp.xin/v1，API Key 填 mock-key。测试模型可填 mock-chat、mock-reasoning、mock-image 或 mock-video。

对话与流式输出

OpenAI Chat Completions。流式请求把 stream 设为 true，使用 curl -N 查看 SSE。

curl https://capi-mock.minapp.xin/v1/chat/completions \
  -H 'Authorization: Bearer mock-key' \
  -H 'Content-Type: application/json' \
  -d '{"model":"mock-chat","messages":[{"role":"user","content":"你好"}]}'

同一固定回复也支持 /v1/responses、Anthropic /v1/messages 与 Gemini /v1beta/models/{model}:generateContent。

按场景测试

复制任一示例运行。所有示例使用默认密钥 mock-key。

图片生成

接口返回仓库内小样图 deno.png 的 Base64；也可直接请求图片 URL。

curl https://capi-mock.minapp.xin/v1/images/generations \
  -H 'Authorization: Bearer mock-key' -H 'Content-Type: application/json' \
  -d '{"model":"mock-image","prompt":"一只水豚"}'

curl https://capi-mock.minapp.xin/assets/deno.png \
  -H 'Authorization: Bearer mock-key' -o deno.png
决策模型（SystemOne）

返回确定的 boolean、noul、string 与 number 答案，可用于联调决策数据解析。

curl https://capi-mock.minapp.xin/v1/systemone \
  -H 'Authorization: Bearer mock-key' -H 'Content-Type: application/json' \
  -d '{"model":"typesafe-ai/jev","questions":{"q1":{"type":"boolean"},"q2":{"type":"noul"},"q3":{"type":"string"},"q4":{"type":"number"}}}'
视频生成与轮询

提交任务后按返回的 ID 查询；默认前两次为处理中，随后成功并返回 demo_url。

# 1. 提交，记录响应里的 id
curl https://capi-mock.minapp.xin/v1/videos \
  -H 'Authorization: Bearer mock-key' -H 'Content-Type: application/json' \
  -d '{"model":"mock-video","prompt":"海边日落"}'

# 2. 将任务 ID 替换成上一步返回的 id，重复请求直到 status=succeeded
curl https://capi-mock.minapp.xin/v1/tasks/mock_video_1 \
  -H 'Authorization: Bearer mock-key'

# 3. 成功后下载响应 demo_url 指向的视频
curl https://capi-mock.minapp.xin/assets/demo.mp4 \
  -H 'Authorization: Bearer mock-key' -o demo.mp4
错误处理与健康检查

通过 X-Mock-Status 注入 HTTP 400–599 错误；健康检查无需鉴权。

curl https://capi-mock.minapp.xin/v1/chat/completions \
  -H 'Authorization: Bearer mock-key' -H 'X-Mock-Status: 429' \
  -H 'Content-Type: application/json' \
  -d '{"model":"mock-chat","messages":[]}'

curl https://capi-mock.minapp.xin/healthz

Agent 使用约定

  • 测试 CAPI 时，将渠道 Base URL 设为本页地址加 /v1，并使用示例 API Key。
  • 先查 GET /v1/models，再用对应模型 ID 调用能力接口。
  • 视频是异步任务：保存提交响应的任务 ID 并轮询任务状态；成功后再取 demo_url。
  • 响应为固定模拟数据，用于验证接入流程，不代表真实模型质量或生成结果。
